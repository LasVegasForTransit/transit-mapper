# Support

TransitMapper is maintained by Las Vegans for Better Transit. It is in open
beta, so features, workflows, and data formats may change before a stable
release.

## Product bugs and ideas

Open a [GitHub issue](https://github.com/LasVegasForTransit/transit-mapper/issues)
for a reproducible bug, feature idea, usage question, or documentation
problem. Include the steps that led to the problem and what you expected.

## Organization questions

Email [hello@lasvegasfortransit.org](mailto:hello@lasvegasfortransit.org) for
questions about Las Vegans for Better Transit or its stewardship of the
project.

## Security reports

Do not report an exploitable vulnerability in a public issue. Follow the
[security policy](SECURITY.md) to email
[security@lasvegasfortransit.org](mailto:security@lasvegasfortransit.org) or
use GitHub private vulnerability reporting.

## Media inquiries

Use the media contact published at
[lasvegasfortransit.org](https://lasvegasfortransit.org).
