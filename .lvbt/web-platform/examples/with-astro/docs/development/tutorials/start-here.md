# Start here

Follow this repository's [README](../../../README.md) for its application layout and local
configuration. Run `pnpm bootstrap`, then `pnpm dev` to start development.

The shared
[developer workflow](https://github.com/LasVegasForTransit/repository-tooling/blob/main/docs/reference/developer-workflow.md)
defines validation, contributions, audits, staging and explicit production promotion. Follow the
mandatory contribution helper in [AGENTS.md](../../../AGENTS.md) when opening a pull request.

The [glossary](../reference/glossary.md) explains the tools this application uses. Extend the shared
standard through application checks and configuration; implement reusable process changes upstream.
