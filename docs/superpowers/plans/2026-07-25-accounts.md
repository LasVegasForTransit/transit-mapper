# Accounts and Permanent Shares Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let someone sign in with Google so their share links never expire, and let them adopt links they published anonymously without changing those URLs.

**Architecture:** The Worker gains a hand-written Google OAuth authorization-code flow (PKCE), opaque session tokens stored hashed in D1, and an `owner_id` on the existing `systems` snapshot table. A share with an owner has `expires_at = NULL`, which is the meaning migration `0002` already reserved. Everything pure and runtime-agnostic lives in `packages/core` so the existing browser-free `pnpm verify` harness can exercise it; only network calls, D1 statements, and route wiring live in `apps/worker`.

**Tech Stack:** Cloudflare Workers, Hono, D1 (SQLite), Web Crypto, React 19, TypeScript, pnpm + Turborepo.

Design spec: [`docs/superpowers/specs/2026-07-25-accounts-design.md`](../specs/2026-07-25-accounts-design.md)

## Global Constraints

- **No new runtime dependencies.** The OAuth flow, session handling, and hashing are written against Web Crypto and `fetch`, both of which the Workers runtime and the browser already provide.
- **`packages/core` must type-check standalone against both the browser and the Workers runtime.** No `window`, `document`, or `localStorage` in core.
- **Testable logic goes in `packages/core`.** `apps/web/scripts/verify.ts` cannot import from `apps/worker`. Anything that needs a test must be pure and live in core.
- **Tests are `check("sentence stating the rule", cond)` calls** appended to `apps/web/scripts/verify.ts`. There is no test framework, no `describe`/`it`, and no assertion library.
- **Migrations are new files** in `apps/worker/src/migrations/`, applied in filename order, never edited after running.
- **`expires_at IS NULL` means "never expires."** Never write it to mean "unset."
- **`/api` holds REST resources only.** The action goes in the HTTP method; collections filter with query parameters. OAuth redirect endpoints mount outside `/api`.
- **Every parameter and prop type is a named interface**, including single-use ones.
- **Documentation ships in the same task as the code it describes.** System architecture goes in `docs/explanation/`.
- **Commit messages are plain imperative sentence case**, matching existing history (`Add daily cron sweep to delete expired shares`). No `feat:`/`fix:` prefixes.
- Every task ends with `pnpm typecheck && pnpm verify` passing.

```ts
// Token primitives shared by the Worker's session and claim handling.
//
// Two encodings live here on purpose. Tokens are stored as hex SHA-256
// because that reads cleanly in a D1 console, while PKCE code challenges
// must be base64url of the raw digest — that encoding is fixed by RFC 7636,
// not a preference.

/** Base64url with padding stripped, per RFC 4648 §5. */
export function toBase64Url(bytes: Uint8Array): string {
  let binary = '';
  for (const byte of bytes) binary += String.fromCharCode(byte);
  return btoa(binary).replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '');
}

/** A cryptographically random, URL-safe token. 32 bytes is 256 bits. */
export function generateToken(byteLength = 32): string {
  const bytes = new Uint8Array(byteLength);
  crypto.getRandomValues(bytes);
  return toBase64Url(bytes);
}

async function sha256(input: string): Promise<Uint8Array> {
  const digest = await crypto.subtle.digest('SHA-256', new TextEncoder().encode(input));
  return new Uint8Array(digest);
}

/** Lowercase hex SHA-256. This is what gets stored; raw tokens never are. */
export async function hashToken(token: string): Promise<string> {
  const bytes = await sha256(token);
  return Array.from(bytes, (b) => b.toString(16).padStart(2, '0')).join('');
}

/** Base64url SHA-256, the encoding PKCE requires for a code challenge. */
export async function sha256Base64Url(input: string): Promise<string> {
  return toBase64Url(await sha256(input));
}
```

```ts
// Cookie helpers. The Workers runtime gives you raw Set-Cookie strings and a
// raw Cookie header, with no parsing either way, so both directions live here
// where `pnpm verify` can exercise them.

export interface CookieOptions {
  /** Seconds. 0 expires the cookie immediately. */
  maxAge?: number;
  httpOnly?: boolean;
  /** Omitted on http://localhost — browsers drop Secure cookies on insecure
   *  origins, which would make local sign-in fail with no visible error. */
  secure?: boolean;
  sameSite?: 'Lax' | 'Strict' | 'None';
  path?: string;
}

export function serializeCookie(name: string, value: string, options: CookieOptions = {}): string {
  const parts = [`${name}=${encodeURIComponent(value)}`];
  if (options.path) parts.push(`Path=${options.path}`);
  if (options.maxAge !== undefined) parts.push(`Max-Age=${options.maxAge}`);
  if (options.httpOnly) parts.push('HttpOnly');
  if (options.secure) parts.push('Secure');
  if (options.sameSite) parts.push(`SameSite=${options.sameSite}`);
  return parts.join('; ');
}

export function parseCookies(header: string | null): Record<string, string> {
  const out: Record<string, string> = {};
  if (!header) return out;
  for (const segment of header.split(';')) {
    const eq = segment.indexOf('=');
    if (eq < 1) continue; // no name, or no separator — skip rather than throw
    const name = segment.slice(0, eq).trim();
    const raw = segment.slice(eq + 1).trim();
    try {
      out[name] = decodeURIComponent(raw);
    } catch {
      out[name] = raw; // a value that isn't valid percent-encoding is used as-is
    }
  }
  return out;
}
```

```ts
// Guards the post-sign-in redirect against being pointed at another site.
//
// The check is allow-list shaped on purpose: anything that isn't obviously a
// same-origin path becomes "/". A blocklist here would be a game of spotting
// every encoding of "//", and losing that game silently hands visitors to
// whoever crafted the link.

// Written with escapes so the character class survives copy-paste.
const CONTROL_CHARACTERS = /[\u0000-\u001F\u007F]/;

export function safeReturnTo(value: string | null | undefined): string {
  if (!value) return '/';
  if (CONTROL_CHARACTERS.test(value)) return '/';
  if (!value.startsWith('/')) return '/';
  // "//host" and "/\host" are both protocol-relative URLs to another origin.
  if (value.startsWith('//') || value.startsWith('/\\')) return '/';
  return value;
}
```

```ts
// Pure parts of the Google OAuth flow. Anything that performs a fetch lives
// in apps/worker/src/auth/google.ts instead, so the URL construction stays
// checkable by `pnpm verify`.

export const GOOGLE_AUTHORIZE_ENDPOINT = 'https://accounts.google.com/o/oauth2/v2/auth';
export const GOOGLE_TOKEN_ENDPOINT = 'https://oauth2.googleapis.com/token';
export const GOOGLE_USERINFO_ENDPOINT = 'https://openidconnect.googleapis.com/v1/userinfo';

/** Identity only. Widening this asks people for access we have no use for. */
export const GOOGLE_SCOPE = 'openid email profile';

export interface AuthorizeUrlParams {
  clientId: string;
  redirectUri: string;
  state: string;
  /** Base64url SHA-256 of the PKCE verifier — see sha256Base64Url. */
  codeChallenge: string;
}

export function buildAuthorizeUrl(params: AuthorizeUrlParams): string {
  const url = new URL(GOOGLE_AUTHORIZE_ENDPOINT);
  url.searchParams.set('response_type', 'code');
  url.searchParams.set('client_id', params.clientId);
  url.searchParams.set('redirect_uri', params.redirectUri);
  url.searchParams.set('scope', GOOGLE_SCOPE);
  url.searchParams.set('state', params.state);
  url.searchParams.set('code_challenge', params.codeChallenge);
  // S256 only. The spec permits "plain", which defeats the point of PKCE.
  url.searchParams.set('code_challenge_method', 'S256');
  return url.toString();
}
```

```ts
// The one place that decides a new share's owner and expiry. They are always
// written together: a share with an owner has expires_at NULL, and a share
// without one has a concrete timestamp. Splitting the decision across call
// sites is how the two drift apart.

/** Seven days. Anonymous shares only; never extended after creation. */
export const ANONYMOUS_SHARE_TTL_MS = 7 * 24 * 60 * 60 * 1000;

export interface NewShareOwnership {
  ownerId: string | null;
  /** NULL means "never expires" — the meaning migration 0002 reserved. */
  expiresAt: number | null;
}

export function newShareOwnership(userId: string | null, now: number): NewShareOwnership {
  if (userId) return { ownerId: userId, expiresAt: null };
  return { ownerId: null, expiresAt: now + ANONYMOUS_SHARE_TTL_MS };
}
```

Create `packages/core/src/share/claim.ts`:

```ts
// Decides what the browser keeps after trying to claim the anonymous shares
// it created. Kept pure so `pnpm verify` can cover it: getting this wrong
// either loses a claimable share forever or retries a hopeless one on every
// single page load.

export interface HeldShare {
  id: string;
  claimToken: string;
}

export interface ClaimResult {
  id: string;
  status: number;
}

export type ClaimOutcome = 'claimed' | 'rejected' | 'retry';

export function claimOutcome(status: number): ClaimOutcome {
  if (status === 200) return 'claimed';
  // 403 wrong or spent token, 409 already owned, 404 share is gone. None of
  // these change on a retry, so the local entry is dead weight.
  if (status === 403 || status === 409 || status === 404) return 'rejected';
  return 'retry';
}

/** Held shares minus the ones that reached a final state. Order preserved.
 *
 *  Generic in the entry type, not fixed to HeldShare: the browser stores a
 *  wider record than the claim request sends, and a caller passing the wider
 *  type must get the wider type back rather than a silently narrowed one. */
export function retainedShares<T extends HeldShare>(held: T[], results: ClaimResult[]): T[] {
  const settled = new Set(
    results.filter((r) => claimOutcome(r.status) !== 'retry').map((r) => r.id),
  );
  return held.filter((share) => !settled.has(share.id));
}
```

```sql
--
-- Shaped after better-auth's user/session/account tables, so swapping this
-- hand-written implementation for that library later stays cheap. Two
-- deliberate differences are noted on the columns below.

CREATE TABLE users (
  id         TEXT PRIMARY KEY,
  -- Profile data used to label the account in the UI. Deliberately NOT
  -- unique and NOT identity: people change the email on a Google account,
  -- and the provider's subject id does not change with it. (better-auth
  -- marks this unique; keying on the provider subject instead avoids a
  -- migration if a second provider is ever added.)
  email      TEXT NOT NULL,
  name       TEXT,
  image      TEXT,
  created_at INTEGER NOT NULL
);

-- One row per linked provider identity. Only 'google' exists today.
CREATE TABLE accounts (
  id          TEXT PRIMARY KEY,
  user_id     TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  provider_id TEXT NOT NULL,
  -- The provider's subject claim ('sub'). This is the stable identity.
  account_id  TEXT NOT NULL,
  created_at  INTEGER NOT NULL,
  UNIQUE (provider_id, account_id)
);

CREATE TABLE sessions (
  -- SHA-256 of the cookie value. The raw token is never stored, so read
  -- access to this database is not enough to mint a working cookie.
  -- (better-auth stores the token in plaintext; this is the second
  -- deliberate difference, and it costs one hash per authenticated request.)
  token_hash TEXT PRIMARY KEY,
  user_id    TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  created_at INTEGER NOT NULL,
  expires_at INTEGER NOT NULL
);

-- it. There is no account-deletion interface yet; this defines the correct
-- behavior for a manual deletion so it can't quietly do the wrong thing.
ALTER TABLE systems ADD COLUMN owner_id TEXT REFERENCES users(id) ON DELETE CASCADE;

-- SHA-256 of a one-time secret handed to the creator of an anonymous share.
-- Set to NULL on adoption, so a share can be claimed exactly once.
ALTER TABLE systems ADD COLUMN claim_hash TEXT;

-- Supports GET /api/systems?owner=me.
CREATE INDEX systems_owner_id ON systems(owner_id);
-- Supports the cron sweep of expired sessions.
CREATE INDEX sessions_expires_at ON sessions(expires_at);
```

```ts
import { generateToken, hashToken } from '@transitmapper/core/auth/tokens';
import type { SessionUser } from '@transitmapper/core/auth/contract';

/** Thirty days. Long enough that a casual user isn't signed out between
 *  visits, short enough that an abandoned session doesn't live forever. */
export const SESSION_TTL_MS = 30 * 24 * 60 * 60 * 1000;

/** A session with less than this left is extended on use, so somebody
 *  active is never signed out mid-edit. At most one write per week. */
export const SESSION_REFRESH_THRESHOLD_MS = 7 * 24 * 60 * 60 * 1000;

export const SESSION_COOKIE = 'tm_session';

/** Creates a session row and returns the raw token for the cookie. The raw
 *  token is returned exactly once and is never stored. */
export async function createSession(db: D1Database, userId: string, now: number): Promise<string> {
  const token = generateToken();
  await db
    .prepare(
      'INSERT INTO sessions (token_hash, user_id, created_at, expires_at) VALUES (?, ?, ?, ?)',
    )
    .bind(await hashToken(token), userId, now, now + SESSION_TTL_MS)
    .run();
  return token;
}

/** Resolves a cookie value to its user, or null. Deletes the row on the spot
 *  if it has expired, mirroring how getActiveShare treats expired shares. */
export async function resolveSession(
  db: D1Database,
  token: string,
  now: number,
): Promise<SessionUser | null> {
  const tokenHash = await hashToken(token);
  const row = await db
    .prepare(
      `SELECT s.expires_at, u.id, u.email, u.name, u.image
         FROM sessions s
         JOIN users u ON u.id = s.user_id
        WHERE s.token_hash = ?`,
    )
    .bind(tokenHash)
    .first<{
      expires_at: number;
      id: string;
      email: string;
      name: string | null;
      image: string | null;
    }>();

  if (!row) return null;

  if (row.expires_at < now) {
    await db.prepare('DELETE FROM sessions WHERE token_hash = ?').bind(tokenHash).run();
    return null;
  }

  if (row.expires_at - now < SESSION_REFRESH_THRESHOLD_MS) {
    await db
      .prepare('UPDATE sessions SET expires_at = ? WHERE token_hash = ?')
      .bind(now + SESSION_TTL_MS, tokenHash)
      .run();
  }

  return { id: row.id, email: row.email, name: row.name, image: row.image };
}

export async function deleteSession(db: D1Database, token: string): Promise<void> {
  await db
    .prepare('DELETE FROM sessions WHERE token_hash = ?')
    .bind(await hashToken(token))
    .run();
}

/** Backstop for sessions nobody ever presents again, so the lazy delete in
 *  resolveSession never fires for them. Called from the daily cron. */
export async function deleteExpiredSessions(db: D1Database, now: number): Promise<void> {
  await db.prepare('DELETE FROM sessions WHERE expires_at < ?').bind(now).run();
}
```

```ts
import { shortId } from '@transitmapper/core/model/ids';
import type { SessionUser } from '@transitmapper/core/auth/contract';

export interface ProviderProfile {
  providerId: string;
  /** The provider's stable subject id, not the email. */
  accountId: string;
  email: string;
  name: string | null;
  image: string | null;
}

/** Finds the user behind a provider identity, creating one on first sign-in.
 *
 *  Lookup is by (provider_id, account_id) only. Matching on email instead is
 *  the classic account-takeover path when a provider doesn't verify
 *  addresses, and with a single provider it would buy nothing. If a second
 *  provider is added, linking needs its own decision — link only when both
 *  providers report a verified email. */
export async function upsertUser(
  db: D1Database,
  profile: ProviderProfile,
  now: number,
): Promise<SessionUser> {
  const existing = await db
    .prepare(
      `SELECT u.id, u.email, u.name, u.image
         FROM accounts a
         JOIN users u ON u.id = a.user_id
        WHERE a.provider_id = ? AND a.account_id = ?`,
    )
    .bind(profile.providerId, profile.accountId)
    .first<{ id: string; email: string; name: string | null; image: string | null }>();

  if (existing) {
    // Refresh the profile so a changed name or picture shows up on the next
    // sign-in. The email is stored but never used to find the account.
    await db
      .prepare('UPDATE users SET email = ?, name = ?, image = ? WHERE id = ?')
      .bind(profile.email, profile.name, profile.image, existing.id)
      .run();
    return { id: existing.id, email: profile.email, name: profile.name, image: profile.image };
  }

  const userId = `user_${shortId(12)}`;
  await db.batch([
    db
      .prepare('INSERT INTO users (id, email, name, image, created_at) VALUES (?, ?, ?, ?, ?)')
      .bind(userId, profile.email, profile.name, profile.image, now),
    db
      .prepare(
        'INSERT INTO accounts (id, user_id, provider_id, account_id, created_at) VALUES (?, ?, ?, ?, ?)',
      )
      .bind(`acct_${shortId(12)}`, userId, profile.providerId, profile.accountId, now),
  ]);

  return { id: userId, email: profile.email, name: profile.name, image: profile.image };
}
```

```ts
import type { Context } from 'hono';
import { parseCookies } from '@transitmapper/core/auth/cookies';
import type { SessionUser } from '@transitmapper/core/auth/contract';
import type { Env } from '../env';
import { resolveSession, SESSION_COOKIE } from './session';

type AppContext = Context<{ Bindings: Env }>;

/** The signed-in user, or null. Safe to call on any route. */
export async function currentUser(c: AppContext): Promise<SessionUser | null> {
  const token = parseCookies(c.req.header('cookie') ?? null)[SESSION_COOKIE];
  if (!token) return null;
  return resolveSession(c.env.DB, token, Date.now());
}

/** The signed-in user, or a 401 Response the caller returns directly. */
export async function requireUser(c: AppContext): Promise<SessionUser | Response> {
  const user = await currentUser(c);
  if (!user) return c.json({ error: 'Not signed in' }, 401);
  return user;
}

/** Rejects state-changing requests that didn't come from our own pages.
 *
 *  SameSite=Lax already keeps the session cookie off a cross-site POST, PUT,
 *  or DELETE. This is a second, independent barrier that doesn't depend on
 *  the browser's cookie policy being implemented correctly. A missing Origin
 *  header is allowed: non-browser clients don't send one, and they have no
 *  cookie riding along to abuse. */
export function enforceSameOrigin(c: AppContext): Response | null {
  const origin = c.req.header('origin');
  if (!origin) return null;
  if (origin !== new URL(c.req.url).origin) {
    return c.json({ error: 'Cross-origin request rejected' }, 403);
  }
  return null;
}
```

```ts
import { GOOGLE_TOKEN_ENDPOINT, GOOGLE_USERINFO_ENDPOINT } from '@transitmapper/core/auth/google';
import type { Env } from '../env';
import type { ProviderProfile } from './users';

export function googleConfigured(env: Env): boolean {
  return Boolean(env.GOOGLE_CLIENT_ID && env.GOOGLE_CLIENT_SECRET);
}

export interface ExchangeCodeParams {
  clientId: string;
  clientSecret: string;
  code: string;
  codeVerifier: string;
  redirectUri: string;
}

/** Trades the authorization code for an access token. Throws on failure; the
 *  caller turns that into a 502. */
export async function exchangeCode(params: ExchangeCodeParams): Promise<string> {
  const response = await fetch(GOOGLE_TOKEN_ENDPOINT, {
    method: 'POST',
    headers: { 'content-type': 'application/x-www-form-urlencoded' },
    body: new URLSearchParams({
      grant_type: 'authorization_code',
      client_id: params.clientId,
      client_secret: params.clientSecret,
      code: params.code,
      code_verifier: params.codeVerifier,
      redirect_uri: params.redirectUri,
    }),
  });

  if (!response.ok) {
    throw new Error(`Google token exchange failed (${response.status})`);
  }

  const body = (await response.json()) as { access_token?: string };
  if (!body.access_token) throw new Error('Google token response had no access_token');
  return body.access_token;
}

/** Reads the profile from the userinfo endpoint.
 *
 *  The token response also carries an id_token, and decoding that would save
 *  a round trip. It would also mean verifying `iss` and `aud` and handling a
 *  JWT by hand. One extra HTTPS call avoids all of that and leaves this
 *  readable by someone who has not implemented OIDC before. */
export async function fetchGoogleProfile(accessToken: string): Promise<ProviderProfile> {
  const response = await fetch(GOOGLE_USERINFO_ENDPOINT, {
    headers: { authorization: `Bearer ${accessToken}` },
  });

  if (!response.ok) {
    throw new Error(`Google userinfo failed (${response.status})`);
  }

  const body = (await response.json()) as {
    sub?: string;
    email?: string;
    name?: string;
    picture?: string;
  };

  if (!body.sub || !body.email) {
    throw new Error('Google userinfo response was missing sub or email');
  }

  return {
    providerId: 'google',
    accountId: body.sub,
    email: body.email,
    name: body.name ?? null,
    image: body.picture ?? null,
  };
}
```

```ts
import { Hono } from 'hono';
import { buildAuthorizeUrl } from '@transitmapper/core/auth/google';
import { safeReturnTo } from '@transitmapper/core/auth/returnTo';
import { generateToken, sha256Base64Url } from '@transitmapper/core/auth/tokens';
import {
  parseCookies,
  serializeCookie,
  type CookieOptions,
} from '@transitmapper/core/auth/cookies';
import type { Env } from '../env';
import { createSession, SESSION_COOKIE, SESSION_TTL_MS } from './session';
import { exchangeCode, fetchGoogleProfile, googleConfigured } from './google';
import { upsertUser } from './users';

const STATE_COOKIE = 'tm_oauth_state';
const VERIFIER_COOKIE = 'tm_oauth_verifier';
const RETURN_COOKIE = 'tm_oauth_return';

/** Ten minutes is longer than any real sign-in takes and short enough that an
 *  abandoned attempt leaves nothing behind. */
const OAUTH_COOKIE_TTL_SECONDS = 600;

/** Browsers drop Secure cookies on insecure origins, so setting it
 *  unconditionally would make local development fail with no visible error. */
function isSecure(url: string): boolean {
  return new URL(url).protocol === 'https:';
}

/** SameSite=Lax, not Strict. The callback arrives as a top-level GET
 *  navigation from Google's origin: Lax sends cookies on that navigation and
 *  Strict does not, so Strict would break the flow outright. Passing an empty
 *  value clears the cookie. */
function oauthCookie(name: string, value: string, url: string): string {
  const options: CookieOptions = {
    maxAge: value ? OAUTH_COOKIE_TTL_SECONDS : 0,
    httpOnly: true,
    secure: isSecure(url),
    sameSite: 'Lax',
    path: '/',
  };
  return serializeCookie(name, value, options);
}

function redirectUriFor(url: string): string {
  return new URL('/auth/google/callback', url).toString();
}

export const authRoutes = new Hono<{ Bindings: Env }>();

authRoutes.get('/auth/google', async (c) => {
  if (!googleConfigured(c.env)) {
    return c.json({ error: 'Sign-in is not configured on this deployment' }, 503);
  }

  const state = generateToken();
  const verifier = generateToken();
  const returnTo = safeReturnTo(c.req.query('returnTo'));

  const url = buildAuthorizeUrl({
    clientId: c.env.GOOGLE_CLIENT_ID!,
    redirectUri: redirectUriFor(c.req.url),
    state,
    codeChallenge: await sha256Base64Url(verifier),
  });

  const headers = new Headers({ location: url });
  headers.append('set-cookie', oauthCookie(STATE_COOKIE, state, c.req.url));
  headers.append('set-cookie', oauthCookie(VERIFIER_COOKIE, verifier, c.req.url));
  headers.append('set-cookie', oauthCookie(RETURN_COOKIE, returnTo, c.req.url));
  return new Response(null, { status: 302, headers });
});

authRoutes.get('/auth/google/callback', async (c) => {
  if (!googleConfigured(c.env)) {
    return c.json({ error: 'Sign-in is not configured on this deployment' }, 503);
  }

  const cookies = parseCookies(c.req.header('cookie') ?? null);
  const state = c.req.query('state');
  const code = c.req.query('code');

  // Double-submit: the state in the URL must match the one in the browser's
  // cookie. Comparing against a value the browser holds is what lets this
  // work without any server-side signing key.
  if (!state || !cookies[STATE_COOKIE] || state !== cookies[STATE_COOKIE]) {
    return c.json({ error: 'Sign-in request could not be verified' }, 400);
  }
  if (!code || !cookies[VERIFIER_COOKIE]) {
    return c.json({ error: 'Sign-in request was incomplete' }, 400);
  }

  let profile;
  try {
    const accessToken = await exchangeCode({
      clientId: c.env.GOOGLE_CLIENT_ID!,
      clientSecret: c.env.GOOGLE_CLIENT_SECRET!,
      code,
      codeVerifier: cookies[VERIFIER_COOKIE],
      redirectUri: redirectUriFor(c.req.url),
    });
    profile = await fetchGoogleProfile(accessToken);
  } catch {
    return c.json({ error: 'Could not complete sign-in with Google' }, 502);
  }

  const now = Date.now();
  const user = await upsertUser(c.env.DB, profile, now);
  const sessionToken = await createSession(c.env.DB, user.id, now);

  const headers = new Headers({ location: safeReturnTo(cookies[RETURN_COOKIE]) });
  headers.append(
    'set-cookie',
    serializeCookie(SESSION_COOKIE, sessionToken, {
      maxAge: Math.floor(SESSION_TTL_MS / 1000),
      httpOnly: true,
      secure: isSecure(c.req.url),
      sameSite: 'Lax',
      path: '/',
    }),
  );
  // Clear the three single-use cookies.
  headers.append('set-cookie', oauthCookie(STATE_COOKIE, '', c.req.url));
  headers.append('set-cookie', oauthCookie(VERIFIER_COOKIE, '', c.req.url));
  headers.append('set-cookie', oauthCookie(RETURN_COOKIE, '', c.req.url));
  return new Response(null, { status: 302, headers });
});
```

```ts
export interface ShareRow {
  id: string;
  system: TransitSystem;
  createdAt: number;

// Look up a share by id, treating an expired-but-not-yet-swept row as if it
// doesn't exist (and deleting it on the spot) — shared by the JSON API and
// the /s/:id HTML route so the expiry rule only lives in one place.
//
// An owned share has expires_at NULL and is therefore never treated as
// expired. That is the whole ownership rule, enforced here by the null check.
export async function getActiveShare(db: D1Database, id: string): Promise<ShareRow | null> {
  const row = await db
    .prepare('SELECT id, data, created_at, expires_at FROM systems WHERE id = ?')
    .bind(id)
    .first<{ id: string; data: string; created_at: number; expires_at: number | null }>();

  if (!row) return null;

  if (row.expires_at !== null && row.expires_at < Date.now()) {
    await db.prepare('DELETE FROM systems WHERE id = ?').bind(id).run();
    return null;
  }

  return { id: row.id, system: JSON.parse(row.data), createdAt: row.created_at };
}
```

```ts
import { Hono } from 'hono';
import { parseSystem } from '@transitmapper/core/model/serialize';
import { shortId } from '@transitmapper/core/model/ids';
import { newShareOwnership } from '@transitmapper/core/share/ownership';
import { generateToken, hashToken } from '@transitmapper/core/auth/tokens';
import type { CreateShareResponse, GetShareResponse } from '@transitmapper/core/share/contract';
import type { ClaimRequest, OwnedSharesResponse } from '@transitmapper/core/auth/contract';
import type { Env } from '../env';
import { currentUser, enforceSameOrigin, requireUser } from '../auth/middleware';
import { getActiveShare } from '../share';

const MAX_BODY_BYTES = 1_000_000; // ~1 MB — generous for a hand-drawn system.

export const systemRoutes = new Hono<{ Bindings: Env }>();

/** The collection is never enumerable. `owner=me` is the only filter, and
 *  asking without it is a client bug rather than a request for everything. */
systemRoutes.get('/api/systems', async (c) => {
  if (c.req.query('owner') !== 'me') {
    return c.json({ error: 'A supported filter is required (owner=me)' }, 400);
  }

  const user = await requireUser(c);
  if (user instanceof Response) return user;

  const { results } = await c.env.DB.prepare(
    'SELECT id, name, created_at FROM systems WHERE owner_id = ? ORDER BY created_at DESC',
  )
    .bind(user.id)
    .all<{ id: string; name: string; created_at: number }>();

  return c.json<OwnedSharesResponse>({
    shares: results.map((row) => ({ id: row.id, name: row.name, createdAt: row.created_at })),
  });
});

// Create an immutable snapshot of a system and return its share id.
systemRoutes.post('/api/systems', async (c) => {
  const rejected = enforceSameOrigin(c);
  if (rejected) return rejected;

  const raw = await c.req.text();
  if (raw.length > MAX_BODY_BYTES) {
    return c.json({ error: 'System too large' }, 413);
  }

  let system;
  try {
    const body = JSON.parse(raw) as { system?: unknown };
    system = parseSystem(body.system);
  } catch (e) {
    return c.json({ error: `Invalid system: ${(e as Error).message}` }, 400);
  }

  const user = await currentUser(c);
  const id = shortId(10);
  const now = Date.now();
  const { ownerId, expiresAt } = newShareOwnership(user?.id ?? null, now);

  // Anonymous shares get a one-time secret so their creator can adopt them
  // after signing in. Only the hash is stored; the secret is returned once
  // and never recoverable from the database.
  const claimToken = ownerId ? null : generateToken(16);
  const claimHash = claimToken ? await hashToken(claimToken) : null;

  await c.env.DB.prepare(
    `INSERT INTO systems (id, name, data, created_at, expires_at, owner_id, claim_hash)
     VALUES (?, ?, ?, ?, ?, ?, ?)`,
  )
    .bind(id, system.name.slice(0, 200), JSON.stringify(system), now, expiresAt, ownerId, claimHash)
    .run();

  return c.json<CreateShareResponse>(claimToken ? { id, claimToken } : { id });
});

// Fetch a shared system snapshot.
systemRoutes.get('/api/systems/:id', async (c) => {
  const share = await getActiveShare(c.env.DB, c.req.param('id'));
  if (!share) return c.json({ error: 'Not found' }, 404);

  return c.json<GetShareResponse>(share);
});

/** Adopt an anonymous share.
 *
 *  Two credentials are required and neither is sufficient alone: the session
 *  cookie says who is claiming, and the claim token proves they created it.
 *  Without the token, anyone who merely saw a share URL could take it over
 *  and then delete it.
 *
 *  PUT because the effect is idempotent — the owner ends up set to the
 *  caller, and replaying changes nothing. */
systemRoutes.put('/api/systems/:id/owner', async (c) => {
  const rejected = enforceSameOrigin(c);
  if (rejected) return rejected;

  const user = await requireUser(c);
  if (user instanceof Response) return user;

  let claimToken: string;
  try {
    const body = (await c.req.json()) as ClaimRequest;
    if (typeof body.claimToken !== 'string' || !body.claimToken) throw new Error();
    claimToken = body.claimToken;
  } catch {
    return c.json({ error: 'A claimToken is required' }, 400);
  }

  const share = await getActiveShare(c.env.DB, c.req.param('id'));
  if (!share) return c.json({ error: 'Not found' }, 404);

  const result = await c.env.DB.prepare(
    `UPDATE systems
        SET owner_id = ?, expires_at = NULL, claim_hash = NULL
      WHERE id = ? AND claim_hash = ? AND owner_id IS NULL`,
  )
    .bind(user.id, share.id, await hashToken(claimToken))
    .run();

  if (result.meta.changes === 0) {
    // Either the token was wrong or spent, or somebody already owns this.
    // Distinguishing the two tells an attacker which half they got right.
    const owned = await c.env.DB.prepare('SELECT owner_id FROM systems WHERE id = ?')
      .bind(share.id)
      .first<{ owner_id: string | null }>();
    if (owned?.owner_id) return c.json({ error: 'Already claimed' }, 409);
    return c.json({ error: 'Claim rejected' }, 403);
  }

  return c.json({ id: share.id, name: share.system.name, createdAt: share.createdAt });
});

systemRoutes.delete('/api/systems/:id', async (c) => {
  const rejected = enforceSameOrigin(c);
  if (rejected) return rejected;

  const user = await requireUser(c);
  if (user instanceof Response) return user;

  const result = await c.env.DB.prepare('DELETE FROM systems WHERE id = ? AND owner_id = ?')
    .bind(c.req.param('id'), user.id)
    .run();

  // Same response whether the share never existed or belongs to somebody
  // else — otherwise this endpoint reports which share ids are real.
  if (result.meta.changes === 0) return c.json({ error: 'Not found' }, 404);
  return c.body(null, 204);
});
```

```ts
import type { HeldShare } from '@transitmapper/core/share/claim';

// Anonymous shares this browser created, with the one-time secret needed to
// adopt them after signing in. Kept separate from the system library in
// localStore.ts: that stores systems you edit, this stores links you
// published, and the two have different lifetimes.
//
// The claim secret lives in localStorage, which any script on this origin can
// read. That is the same exposure as the share URL itself, and the worst a
// reader can do is take ownership of a link they could already open.
const SHARES_KEY = 'transitmapper:shares';

export function heldShares(): HeldShare[] {
  try {
    const raw = localStorage.getItem(SHARES_KEY);
    if (!raw) return [];
    const parsed = JSON.parse(raw);
    if (!Array.isArray(parsed)) return [];
    return parsed.filter(
      (entry): entry is HeldShare =>
        !!entry && typeof entry.id === 'string' && typeof entry.claimToken === 'string',
    );
  } catch {
    return [];
  }
}

export function setHeldShares(shares: HeldShare[]): void {
  try {
    localStorage.setItem(SHARES_KEY, JSON.stringify(shares));
  } catch {
    // Storage full or unavailable — the share link still works, it just
    // can't be adopted later.
  }
}

export function recordShare(share: HeldShare): void {
  setHeldShares([...heldShares().filter((held) => held.id !== share.id), share]);
}
```

```tsx
import {
  createContext,
  useCallback,
  useContext,
  useEffect,
  useMemo,
  useState,
  type ReactNode,
} from 'react';
import type { AuthProvider, SessionUser } from '@transitmapper/core/auth/contract';
import { retainedShares, type ClaimResult } from '@transitmapper/core/share/claim';
import { heldShares, setHeldShares } from '../storage/shareStore';
import { claimShare, fetchProviders, fetchSession, signOut as signOutRequest } from './api';

export interface SessionState {
  user: SessionUser | null;
  /** Empty when this deployment has no sign-in configured, which is the
   *  signal to hide the menu item rather than show a broken one. */
  providers: AuthProvider[];
  loading: boolean;
  signOut: () => Promise<void>;
}

const SessionContext = createContext<SessionState | null>(null);

export interface SessionProviderProps {
  children: ReactNode;
}

/** Reads the session once for the whole app, and on finding one, adopts any
 *  anonymous shares this browser still holds claim tokens for.
 *
 *  This is a provider rather than a hook each consumer calls because the
 *  claim wave must run exactly once. Two components each running it would
 *  race to claim the same shares and both write the local store.
 *
 *  The claim runs on load rather than only right after the OAuth redirect: a
 *  share created in one browser session is still claimable in the next, and
 *  the redirect isn't observable from here anyway. Entries that reach a final
 *  state are dropped, so a signed-in user holding nothing does no work. */
export function SessionProvider({ children }: SessionProviderProps) {
  const [user, setUser] = useState<SessionUser | null>(null);
  const [providers, setProviders] = useState<AuthProvider[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    let cancelled = false;

    void (async () => {
      const [session, available] = await Promise.all([
        fetchSession().catch(() => null),
        fetchProviders().catch(() => []),
      ]);
      if (cancelled) return;

      setUser(session);
      setProviders(available);
      setLoading(false);

      if (!session) return;

      const held = heldShares();
      if (held.length === 0) return;

      const results: ClaimResult[] = await Promise.all(
        held.map(async (share) => ({ id: share.id, status: await claimShare(share) })),
      );
      if (cancelled) return;
      setHeldShares(retainedShares(held, results));
    })();

    return () => {
      cancelled = true;
    };
  }, []);

  const signOut = useCallback(async () => {
    await signOutRequest();
    setUser(null);
  }, []);

  const value = useMemo<SessionState>(
    () => ({ user, providers, loading, signOut }),
    [user, providers, loading, signOut],
  );

  return <SessionContext.Provider value={value}>{children}</SessionContext.Provider>;
}

export function useSession(): SessionState {
  const ctx = useContext(SessionContext);
  if (!ctx) throw new Error('useSession must be used within <SessionProvider>');
  return ctx;
}
```

```tsx
import { useEffect, useState } from 'react';
import type { OwnedShare } from '@transitmapper/core/auth/contract';
import { deleteShare, fetchOwnedShares } from '../auth/api';

import { Modal } from './Modal';

interface MySharesDialogProps {
  onClose: () => void;
}

// Same wording and thresholds as SystemsDialog's own relativeTime, so the two
// dialogs never disagree about how long ago something happened.
function relativeTime(ts: number): string {
  const minutes = Math.round((Date.now() - ts) / 60_000);
  if (minutes < 1) return 'just now';
  if (minutes < 60) return `${minutes}m ago`;
  const hours = Math.round(minutes / 60);
  if (hours < 24) return `${hours}h ago`;
  const days = Math.round(hours / 24);
  if (days < 30) return `${days}d ago`;
  return new Date(ts).toLocaleDateString();
}

/** The share links this account owns. Unlike anonymous links these never
 *  expire — see docs/explanation/accounts-and-sessions.md for the rule.
 *  Deliberately reuses SystemsDialog's markup and class names. */
export function MySharesDialog({ onClose }: MySharesDialogProps) {
  const [shares, setShares] = useState<OwnedShare[] | null>(null);
  const [error, setError] = useState('');
  const [confirmingId, setConfirmingId] = useState<string | null>(null);
  const [copiedId, setCopiedId] = useState<string | null>(null);

  useEffect(() => {
    let cancelled = false;
    fetchOwnedShares()
      .then((result) => {
        if (!cancelled) setShares(result);
      })
      .catch((e: Error) => {
        if (!cancelled) setError(e.message);
      });
    return () => {
      cancelled = true;
    };
  }, []);

  const copy = async (id: string) => {
    try {
      await navigator.clipboard.writeText(`${window.location.origin}/s/${id}`);
      setCopiedId(id);
      setTimeout(() => setCopiedId(null), 1500);
    } catch {
      // clipboard blocked — Open still gets them to the link
    }
  };

  const remove = async (id: string) => {
    try {
      await deleteShare(id);
      setShares((current) => (current ?? []).filter((share) => share.id !== id));
    } catch (e) {
      setError((e as Error).message);
    }
    setConfirmingId(null);
  };

  return (
    <Modal
      title="My shares"
      description="Share links you own. These don't expire."
      onClose={onClose}
    >
      {error && <p className="error-text">{error}</p>}
      {!shares && !error && <p className="panel-hint">Loading your shares…</p>}
      {shares?.length === 0 && (
        <p className="panel-hint">Nothing shared yet — use Share to publish a link to a system.</p>
      )}
      {shares && shares.length > 0 && (
        <ul className="systems-list">
          {shares.map((share) => (
            <li key={share.id} className="systems-row">
              <a className="systems-open" href={`/s/${share.id}`} target="_blank" rel="noreferrer">
                {share.name || 'Untitled system'}
              </a>
              <span className="systems-meta">{relativeTime(share.createdAt)}</span>
              <IconButton
                icon={copiedId === share.id ? 'check' : 'copy'}
                label={copiedId === share.id ? 'Link copied' : 'Copy link'}
                onClick={() => void copy(share.id)}
              />
              {confirmingId === share.id ? (
                <span className="systems-confirm">
                  <button
                    type="button"
                    className="danger-btn systems-confirm-btn"
                    onClick={() => void remove(share.id)}
                  >
                    Delete
                  </button>
                  <button
                    type="button"
                    className="ghost-btn systems-confirm-btn"
                    onClick={() => setConfirmingId(null)}
                  >
                    Cancel
                  </button>
                </span>
              ) : (
                <IconButton
                  icon="trash"
                  label="Delete share"
                  onClick={() => setConfirmingId(share.id)}
                />
              )}
            </li>
          ))}
        </ul>
      )}
    </Modal>
  );
}
```

Change `heldShares` to filter on the wider shape, keeping the same tolerance for junk:

```ts
export function heldShares(): StoredShare[] {
  try {
    const raw = localStorage.getItem(SHARES_KEY);
    if (!raw) return [];
    const parsed = JSON.parse(raw);
    if (!Array.isArray(parsed)) return [];
    return parsed.filter(
      (entry): entry is StoredShare =>
        !!entry &&
        typeof entry.id === 'string' &&
        typeof entry.claimToken === 'string' &&
        typeof entry.systemId === 'string' &&
        typeof entry.createdAt === 'number',
    );
  } catch {
    return [];
  }
}

/** The most recent link this browser made for a given system, if any. */
export function lastShareFor(systemId: string): StoredShare | null {
  const matches = heldShares().filter((share) => share.systemId === systemId);
  if (matches.length === 0) return null;
  return matches.reduce((latest, share) => (share.createdAt > latest.createdAt ? share : latest));
}
```
