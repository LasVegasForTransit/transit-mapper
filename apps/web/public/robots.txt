# Share and embed pages are deliberately crawlable.
#
# They used to be blocked with `Disallow: /s/`, which was the wrong tool for
# the intent. The goal is "don't put people's shared systems in search
# results" — but Disallow stops a crawler fetching the page at all, and the
# bots that build link previews honour it. That turns every pasted share link
# into a blank card: the og: tags are right there and nothing is allowed to
# read them.
#
# "Fetch this, but don't index it" is what noindex means. Both /s/ and /e/
# send `X-Robots-Tag: noindex` (see apps/worker/src/index.ts), so unfurlers
# can read the preview while search engines leave it out.
# On any origin that is not production, the Sitemap line below is dropped by
# scripts/deployment/crawl-directives.ts — it names production, and a sitemap
# for someone else's origin is ignored anyway. Allow stays, for the same reason
# as above: a crawler has to be able to fetch a page to read its noindex.
User-agent: *
Allow: /

Sitemap: https://map.lasvegasfortransit.org/sitemap.xml
