TransitMapper

Privacy

Effective August 13, 2026

TransitMapper is operated by Las Vegans for Better Transit (LVBT). This page explains the limited data used to run shared maps and to learn whether the app is fast and reliable.

Anonymous performance samples

TransitMapper samples 1% of ordinary visits. For the first 24 hours after a release, it samples 5% so problems in a new version can be found quickly. The choice is stable only for that browser tab and build. It uses no visitor or device identifier.

A sampled report may contain only:

  • the public release build and whether the visit used the editor, a shared map, or an embed;
  • coarse loading phase timings and LCP, CLS, and INP performance measurements;
  • categorized byte totals, without resource URLs;
  • cache and service-worker state;
  • coarse device and network tiers; and
  • eight yes-or-no browser capability checks packed into one number.

INP contains the interaction duration only. It does not contain what someone typed, clicked, touched, or selected. These reports are used only to improve TransitMapper's speed and reliability. They are not used for advertising, sold, shared for cross-site tracking, or used to build profiles.

What performance reports never contain

We never collect document or share IDs, document or system names, routes, stations, coordinates, geometry, resource or page URLs, map content, typed content, clicks or other inputs, account IDs, a raw user-agent string, a raw IP address, or a persistent identifier.

Your privacy signals

Global Privacy Control (GPC) or Do Not Track (DNT) set to 1 opts the visit out before performance observers or sampling begin. The server checks the corresponding request signals again before reading a report.

Hosting, storage, and retention

Cloudflare hosts TransitMapper, provides security and rate limiting, and processes the D1 database as LVBT's service provider. Cloudflare necessarily processes request metadata, such as an IP address, to deliver and protect a request. TransitMapper's performance tables do not copy that metadata. Read Cloudflare's privacy policy for Cloudflare's own practices.

Raw performance rows are kept for seven days after a successful daily rollup. Daily aggregates are kept for 90 days. Cloudflare D1 Time Travel may retain restorable database history beyond an ordinary deletion. If LVBT restores an older database during recovery, the normal retention job runs again to clean up restored performance rows that have expired.

Shared-map data is stored in D1 to provide a link someone explicitly creates. A working copy remains in that person's browser. Performance sampling never copies the shared map or its identity into a performance report.

Questions and source

Contact LVBT through the LVBT home page with privacy questions. TransitMapper is open source; the source code shows the report contract and server handling.
